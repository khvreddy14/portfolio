## 🚀 How to Deploy Online for Free

### Method A: Deploy to GitHub Pages (Recommended)
1. In your GitHub account (`khvreddy14`), create a new public repository named:
   ```text
   khvreddy14.github.io
   ```
   *(or create any repository, e.g., `portfolio`)*
2. Push all files from `harsha-portfolio` directly to the `main` branch.
3. In GitHub, go to **Settings &rarr; Pages &rarr; Branch: main &rarr; Save**.
4. Your website will be live in ~1 minute at:
   ```text
   https://khvreddy14.github.io
   ```

### Method B: Deploy to Vercel (Instant 1-Click)
1. Go to [vercel.com](https://vercel.com) and sign in with GitHub.
2. Click **Add New &rarr; Project** and select your portfolio repository.
3. Keep default settings and click **Deploy**.
4. You will get a free production URL like `harsha-portfolio.vercel.app` with instant global SSL.

### Method C: Deploy to Netlify
1. Go to [netlify.com](https://netlify.com) and drag-and-drop the `harsha-portfolio` folder directly into the Netlify Drop area.
2. It goes live immediately with a free HTTPS URL.
